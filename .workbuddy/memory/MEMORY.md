- **浏览器验证环境经验**：agent-browser 需 PowerShell 直调 node + 其 bin/agent-browser.js（bash shim 损坏）；PowerShell 传参会剥引号 → eval JS 代码内禁用引号字符；`click text X` 无效、`find text X click` 有效；展开分组后立即点子项会落在 250ms 展开动画内无效，验证装载用 `eval window.shellOpen(k)` 直调绕过；`*>` 重定向文件为 UTF-16 需转码后 Read。**agent-browser 可能整体挂死（连续 batch 无输出挂 8 分钟+），备用方案：Edge headless + wrapper 页截图**——iframe 加载目标页 `?embed=1`，onload+setTimeout 调 `contentWindow.openCreateModal()`/派发 input 事件填值。**Edge headless 稳妥用法（2026-09-17 验证）**：① 必须用 `Start-Process -Wait -PassThru` 等待退出，普通 `&` 直调会立即返回导致截图文件尚未写出（成功时 stderr 输出 "N bytes written"）；② wrapper 里 iframe src 的中文路径必须按路径段百分号编码且**保留 `/` 字面量**（`[Uri]::EscapeDataString` 会把 `/` 编成 `%2F` 导致 file:// 加载失败，需 `.Replace('%2F','/')` 还原）；③ 场景执行放 iframe 的 `onload` 同步执行即可（无需 setTimeout/virtual-time-budget），截图在 load 后自动触发；④ 测量结果以绝对定位 div 写入页面内随截图读取；⑤ **同一文件的多个 Edit 严禁在同一条消息并行调用**（各自基于旧内容写回会互相覆盖，只有最后一个生效），必须串行执行。shell 布局：`--topnav-h:40px; --tabbar-h:32px`，iframe 内容高度=视口-72px。
