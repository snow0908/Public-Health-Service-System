# 公共卫生服务系统 · 原型设计（V1.0）

> 基于产品规划文档 V1.4 与《86 项功能清单》还原的系统级高保真原型（Element-UI 视觉规范）。
> 原型内部均为**演示数据**，仅用于评审交互逻辑与表单结构，不代表真实业务数据。

## 使用说明

- 从 `02-工作台.html` 或任意模块进入，左侧 19 个模块导航互链，可直接切换；
- 模块内多个功能页通过顶部 **页签（Tab）** 切换；
- 「新建 / 登记 / 报告」类按钮可弹出录入表单弹窗（含必填项 * 标识、表单分段）；
- 推荐使用 Chrome / Edge 打开，分辨率 1440×900 及以上。

## 合规与设计依据

- 国家基本公共卫生服务规范（第三版）
- 《家庭健康档案 WS/T 517—2016》等行业标准
- 三网监测（孕产妇死亡 / 围产儿死亡 / 出生缺陷 / 5 岁以下儿童死亡）
- 孕产妇五色分级、慢病红黄绿分级、39 种法定传染病分类等业务规范

## 待确认项

各模块页内以「待确认」标注的功能点来源于功能清单中的待确认项字段，需与业务方对齐后在下一版原型中固化。
