## 原型设计：index.html 改造为系统框架壳子（脱敏规则内嵌）

目录：`01-公共卫生服务系统产品文档/V1.0/02.需求设计/原型设计/`

### 改动内容
- **index.html**：原为 脱敏规则.html 的逐字节副本（MD5 相同），重写为系统框架壳子——顶栏 + 左侧菜单（框架.js 注入）+ 动态标签栏 + 右侧 iframe 内容区；点击左侧菜单 → 打开/激活标签页 → iframe 装载对应页面（自动附加 `?embed=1`）；每个标签页独立 iframe，切换保状态、关闭销毁；默认落地页「脱敏设置」（初始化写死 `tuomin`，缺失时兜底取 MENU 第一个带 url 的项）。
- **脱敏规则.html**：框架引入改为 `<script src="框架.js" data-page="tuomin" data-embed="auto">`（被 iframe 内嵌或 URL 带 ?embed=1 时自动进入嵌入模式：不注入顶栏/侧栏/标签栏，仅提供 toast/escapeHtml 等公共函数）；`<style>` 内新增 `html.embed-mode` 三条适配样式（main-area 撑满、tabbar 隐藏、toast 上移）。独立打开行为完全不变。
- **框架.js**（增量、向后兼容）：新增 `data-shell` 壳子模式（navigate 转交 `window.shellOpen(key)`，不再整页跳转）与 `data-embed` 嵌入模式（auto 自动检测）；菜单项/子项加 `data-key`；导出 `MENU_CONFIG / findMenuItem / setMenuActive / FRAME_DIR` 供壳子使用；inject() 在嵌入模式仅创建 Toast 容器。
- **死链处理**：MENU 中 `场景配置.html`、`视图管理/视图列表.html` 在本目录不存在，已暂时摘除 url（代码留注释，页面就位后补回）；无 url 菜单项在壳子中显示「功能建设中」占位页（srcdoc）。

### 新增页面约定
页面引入 框架.css/框架.js 并传 `data-page="key" data-embed="auto"`，在 框架.js 的 MENU 中配置 `url` 即可被壳子装载；未配置 url 的菜单项显示占位页。

### 验证（agent-browser 截图）
- 壳子初始加载：自动打开脱敏设置，iframe 嵌入无双重框架 ✓
- 展开日志管理 → 点击访问日志：新标签 + 建设中占位页 + 菜单高亮同步 + 多标签共存 ✓
- 脱敏规则.html 独立打开：完整框架 + 原标签栏，行为不变 ✓

### 环境经验（本机）
- bash 基础命令损坏；PowerShell 会吞 stdout，需写临时文件再读取。
- PowerShell 调 agent-browser：用 npm.cmd 安装；`$ErrorActionPreference='Continue'` + `*> file` 重定向；多步骤必须用 `agent-browser batch` 在单次调用内完成（daemon 随调用结束回收）；file:// 页面需 `--allow-file-access`；batch 内路径用正斜杠。
- agent-browser 对折叠菜单内隐藏元素的 force-click 会落在该位置的可见元素上（测试时需先展开分组）。

### 环境经验（本轮新增）
- Bash 工具跑 agent-browser 失败：sh shim 依赖 dirname/sed/uname 全损坏 → 改用 PowerShell 直调：`& node.exe <prefix>\node_modules\agent-browser\bin\agent-browser.js --allow-file-access batch ...`（prefix = C:\Users\pleas\.workbuddy\binaries\node\versions\22.22.2-3）。
- PowerShell 传参给 node 会剥掉单引号和双引号：eval JS 代码内避免任何引号字符，如 `eval var k=window.MENU_CONFIG[0].children[0].key;window.shellOpen(k)`。
- agent-browser `click text X` 语法无效（报 Done 但不点击）；有效语法是 `find text X click`。
- 展开分组后立即 find 点击子项会落在 250ms max-height 展开动画期间而无效——自动化验证绕过：直调 shellOpen；真实用户点击间隔 >250ms 无此问题。
- `*>` 重定向文件是 UTF-16 编码：Read 工具报二进制，需 `Get-Content -Encoding Unicode | Out-File -Encoding utf8` 转码后再读。

## 原型设计：居民档案「新建个人档案」弹框（第三轮）

同目录 居民档案列表.html 增量。按用户截图还原：点击页头「新建」弹出「新建个人档案」弹框。

### 实现要点
- **结构**：modal-overlay + modal（840px）；标题蓝色；左表单（436px，8 字段：证件类型[默认居民身份证]/证件号+身份证读卡[蓝边按钮]/姓名/性别[请选择]/民族[默认汉族]/联系电话/出生日期/联系地址[省市区下拉 186px + 详细地址 154px]）+ 右回显卡 .pv-card（primary-bg 浅蓝底 + 虚线蓝边，grid 两列，出生年月/联系地址跨双列，值蓝色 --primary）；底部 下一步[蓝]/取消。
- **联动**：表单 input/change → renderPreview() 实时回显；弹框刚打开时 renderPreviewEmpty() 只渲染标签（值全空，贴合截图1）；字数计数（证件号 18/姓名 8/详细地址 50）input 内右侧灰字。
- **身份证自动解析**：证件号满 18 位（正则 `^\d{17}[\dXx]$`）→ 自动填出生日期（slice 6-14）+ 性别（第 17 位奇男偶女）+ toast 提示。
- **出生日期控件**：text/date 双态（focus 切 date + showPicker()，blur 空则回 text 显示"请选择日期"）。
- **下一步校验**：必填缺失 → toast warning 列出缺项；证件号格式校验；通过 → toast success（原型仅演示）。

### 验证（agent-browser 截图，均通过）

- 填写态：证件号 18 位自动解析出生日期 1999-09-07 + 性别女性；回显卡实时显示姓名/民族/出生年月/证件类型/证件号/联系地址蓝色值；计数 18/18、2/8 正常 ✓（cm_filled.png）
