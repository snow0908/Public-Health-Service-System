### 五、踩坑
1. **删字段必须同步清事件绑定数组**。原绑定 `['cmIdType','cmGender','cmBirth','cmCrowd','cmMarriage','cmCreateDate'].forEach(... $(id).addEventListener ...)`：DOM 删掉后 `$(id)` 为 `null` → `addEventListener` 抛 TypeError → **整段脚本静默失效**（表格都不渲染）。删字段时务必 grep 一遍 id 的全部引用点。
2. **失效视图参数不会报错**。`view=women` 不匹配任何分支，`init` 的 if/else 链没有 else，于是停在封面页 —— 表面上「跳过去了」，实际跳错。跨页跳转前先 grep 目标页的视图名（`switchView` 里的 `var isXx = name === 'xxx'`）。
3. **参考图 ≠ 参考页时，用「不受缩放影响的锚点」判断**。本次配图弹框 786×472、行距 48；本仓库 `居民档案列表.html` 弹框 860×460、行距 46。判据：控件高度两边都是 **32**、弹框顶→首行控件顶都是 **64**（48 头 + 16 内距）→ 纵向 1:1，说明配图不是本仓库实现的截图（且配图页表格只有 5 行「产娟呀/张喜喜/…」，与仓库 16 行不同）。此时**以用户点名的参考页为准**，并如实报告差异。
4. `--virtual-time-budget` 下 `window.addEventListener('load', function(){ setTimeout(fn, 80~150) })` 探针**可用**（本次 openCreateModal / 填表 / 校验三处探针均按预期执行）。
5. 读图别靠缩略图：1920 宽的截图缩到 960 后，标签栏「妇女管理」的高亮块会被看成一条 toast。定位 UI 元素一律先**裁切原生分辨率**再看。
