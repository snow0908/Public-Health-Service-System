# 项目长期备忘

## 原型设计（01-公共卫生服务系统产品文档/V1.0/02.需求设计/原型设计/）
- **index.html = 系统框架壳子**：顶栏 + 左侧菜单（框架.js 注入）+ 动态标签栏 + iframe 内容区；点击左侧菜单在右侧装载页面；默认落地页「脱敏设置」（初始化项 key 硬编码为 `tuomin`）。
- **业务页面双模式约定**：页面引入 框架.css/框架.js 时传 `data-page="key" data-embed="auto"`——独立打开带完整框架；被壳子内嵌（URL 带 ?embed=1 或处于 iframe 中）时自动进入嵌入模式（html.embed-mode），只渲染内容区，不注入顶栏/侧栏/标签栏。
- **框架.js 导出**：`MENU_CONFIG / findMenuItem / setMenuActive / FRAME_DIR` 供壳子使用；壳子以 `data-shell="true"` 声明，菜单点击转交 `window.shellOpen(key)`。
- **新增页面流程**：写好页面 HTML（按双模式约定引入框架）→ 在 框架.js MENU 中配置 url → 壳子即可装载；无 url 的菜单项显示「功能建设中」占位页。场景配置/概况视图配置的 url 已摘除（页面未就位），就位后补回。
- **已就位页面**：脱敏规则.html（系统管理/脱敏设置，key `tuomin`）、居民档案列表.html（档案管理/居民档案，key `resident-archives`；分组 key 已由遗留的 `statistics` 改为 `archives`；页面含筛选/24列表格（序号·管理机构·姓名·证件号固定 + 原有字段列 + 补充列：行政区/责任医生/建档医生/建档日期/建档机构/档案完整度%/人群性质/居民状态绿点/银行状态橙点；**前 4 列 sticky 横向冻结**，td 白底、th z-index 须高于普通 th 否则被滚动表头覆盖）/操作下拉/分页，20 行自洽模拟数据；另有"新建个人档案"弹框：左侧单列表单 + 右侧证件号行+回显卡、联系地址整行铺底）、家庭档案.html（档案管理/家庭档案，key `family-archives`；**内容区结构与居民档案完全一致**：tabbar + content-card 四段一体式（page-head/filter-panel/table-wrap/page-foot），家庭主表13列+成员子表嵌套展开（+/-切换，首户默认展开）/分页，10 户模拟数据；filter 引用不存在字段会把全表过滤成空态，需 `(r.xxx || 默认值)` 兜底；新建视图（页内切换，非弹框）：三列 cr-grid 表单 + 三选项卡 + 户主选择弹框带入个档 + 地址五级级联；**表单栅格必须 `repeat(3,minmax(0,1fr))`（纯 1fr 会被长值撑宽列）且 flex 容器需显式 display:flex 否则 input 停在固有宽度约 198px**；除系统生成编号外表单字段一律白底可编辑（用户明确反对 readonly 灰底禁编辑态）；保存流程：保存→tipModal 提示弹框（家庭档案建立成功！+添加家庭成员/取消）→确定切家庭成员 tab 并生成户主行（与户主关系=本人或户主，**操作列注销/删除灰色不可点**，familySaved 防重复，openCreateView 重置空态）；成员弹框双模式 memberMode（owner=选户主点行直接带入 / member=点行展开弹框内"家庭成员信息"录入区，*与户主关系/*血缘关系必填，保存后成员列表 append 行，普通成员操作列编辑/注销可点））。**内容区版式约定：同模块业务页统一用 tabbar+content-card 一体式白卡结构，勿用分离圆角卡片。**。**成员行编辑=行内编辑**：点编辑→该行「与户主关系」「血缘关系」两列变下拉、行高亮 #EDF5FF、操作列变保存/取消（editMemberRow/saveMemberEdit/cancelMemberEdit，同一时间仅一行编辑）；字典走公卫标准并 JS 统一维护（REL_DICT=GB/T 4761-2008 家庭关系代码归类 16 项；BLOOD_DICT=WS 364.3 CV02.01.201 血缘关系代码 6 项：无血缘/直系/三代以内旁系/三代以外旁系/不详/其他），弹框 mmRel/mmBlood 与行内下拉同源（fillDict 动态填充）；血缘列宽 150px 容长值；户主行无编辑钮（注销/删除灰显）。**成员注销=二次确认**：askCancelMember 弹 #cancelModal（modal-sm，含成员名+副文案，红色 .btn-danger 确定注销）→ confirmCancelMember 删行并重排序号、空则恢复空态。**用户原则：新增字段列是补充，原有列一律保留。**
- **框架.css**：设计 token 与公共组件样式（主色 #007AFF）；页面特有样式写在各页 `<style>`。
- 每个 URL 标签页一个独立 iframe：切换标签保留各页状态，关闭标签销毁对应 iframe。
- **浏览器验证环境经验**：agent-browser 需 PowerShell 直调 node + 其 bin/agent-browser.js（bash shim 损坏）；PowerShell 传参会剥引号 → eval JS 代码内禁用引号字符；`click text X` 无效、`find text X click` 有效；展开分组后立即点子项会落在 250ms 展开动画内无效，验证装载用 `eval window.shellOpen(k)` 直调绕过；`*>` 重定向文件为 UTF-16 需转码后 Read。**agent-browser 可能整体挂死（连续 batch 无输出挂 8 分钟+），备用方案：Edge headless + wrapper 页截图**——iframe 加载目标页 `?embed=1`，onload+setTimeout 调 `contentWindow.openCreateModal()`/派发 input 事件填值。**Edge headless 稳妥用法（2026-09-17 验证）**：① 必须用 `Start-Process -Wait -PassThru` 等待退出，普通 `&` 直调会立即返回导致截图文件尚未写出（成功时 stderr 输出 "N bytes written"）；② wrapper 里 iframe src 的中文路径必须按路径段百分号编码且**保留 `/` 字面量**（`[Uri]::EscapeDataString` 会把 `/` 编成 `%2F` 导致 file:// 加载失败，需 `.Replace('%2F','/')` 还原）；③ 场景执行放 iframe 的 `onload` 同步执行即可（无需 setTimeout/virtual-time-budget），截图在 load 后自动触发；④ 测量结果以绝对定位 div 写入页面内随截图读取；⑤ **同一文件的多个 Edit 严禁在同一条消息并行调用**（各自基于旧内容写回会互相覆盖，只有最后一个生效），必须串行执行。shell 布局：`--topnav-h:40px; --tabbar-h:32px`，iframe 内容高度=视口-72px。
